# Covid-19 Tracker (B4A)

An Android app that tracks and displays Covid-19 data, built with **B4A (Basic4Android)**.

## Features
- Worldwide / country Covid-19 stats
- Charts (xChart)
- CSV data parsing
- Text-to-speech welcome

## Requirements
- [B4A (Basic4Android)](https://www.b4x.com/b4a.html) IDE
- Android SDK

## Installation
1. Clone the repository
   ```
   git clone https://github.com/codexvisual/covidApp.git
   ```
2. Open `cov.b4a` in B4A
3. Connect a device (or use the B4A bridge) and click **Run (F5)**

## Notes
- Requires the B4A libraries listed in the project manifest (okhttputils2, xchart, xui views, tts, etc.).
